# Nosotros (versión web)

Versión web de **Nosotros** (distancia, calendario, ciclo, chat y series para dos): https://nosotros-app.xyz

## App de Android

La app de Android vive en otro repositorio: [MiInfcl/nosotros-android](https://github.com/MiInfcl/nosotros-android).

- [Descargar la última versión (Nosotros.apk)](https://github.com/MiInfcl/nosotros-android/releases/latest/download/Nosotros.apk)
- La app se actualiza sola desde ahí (Ajustes → Actualizaciones).

Web y app usan la misma cuenta, y los ajustes se sincronizan entre las dos.
